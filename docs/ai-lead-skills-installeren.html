Je AI-lead-skills.
In vijf minuten in Claude.

Vier skills die je door je opdracht heen helpen: interview voorbereiden en uitwerken, procesmap maken, en van procesmap naar een eerste workflow in Lleverage of n8n. Eén keer toevoegen in claude.ai, daarna werken ze ook in Claude Code op hetzelfde account.

Werkt op Mac en Windows·Geen GitHub-account nodig·Updates komen vanzelf

Stap 1

Open het plus-menu

Ga naar claude.ai, start een nieuwe chat en klik links onder het tekstvak op +.

Stap 2

Kies Plugins, dan Browse plugins

Onder Plugins zie je later ook je geïnstalleerde plugins staan.

Stap 3

Add, dan Add from a repository

Rechtsboven op de knop Add, dan Add marketplace, dan de onderste keuze.

Stap 4

Plak de bron en klik Sync

In het veld URL typ je precies dit: SPAIK-io/ai-lead-skills. De rode waarschuwing is standaard; deze plugin komt van SPAIK.

Stap 5

Zet de plugin aan

Open "Ai lead skills" en zet de schakelaar rechtsboven aan. Er staat "4 skills".

Stap 6

Typ gewoon wat je wilt

Nieuwe chat: "interview voorbereiden", "procesmap maken" of "workflow maken". Claude pakt de juiste skill zelf.

Ook in Claude Code

Gebruik je Claude Code op hetzelfde account: één keer herstarten, dan staan de skills er ook.

Bijwerken

Nieuwe versies komen vanzelf. Nu meteen: open de plugin, drie puntjes, Check for updates. "No changes" betekent: je hebt al de nieuwste.

Zie je "already added"?

Dan staat de bron er al. Niet opnieuw toevoegen: ga naar Discover, zoek "Ai lead skills" en zet hem aan. Loop je vast, app in de groep.
