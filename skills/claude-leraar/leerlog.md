# Leerlog

Het leerlog is het geheugen van de leraar. Geef het na elke les in één tekstblok, zodat de
gebruiker het in het Project kan zetten of de volgende keer kan plakken. Houd het kort: wat er
niet meer toe doet, gaat eruit.

```text
LEERLOG
Laatste les: datum, wat we deden
Leervoorkeur: voorbeeld, uitleg of zelf proberen
Zo wil ik het zien: tekst, schema of voorbeeldpagina
Tijd per week: ...
Doel over drie maanden: ...
Werk dat me tijd kost: ...
Fase: ... van 7 (hoe vaak zelf gedaan: ...)
Wat ik kan: ...
Terugkerend werk: taak, hoe vaak, welke correcties ik steeds maak
Mijn skills: naam, sinds wanneer, laatst verbeterd
Mijn correcties: per les één regel, wat ik moest verbeteren aan wat Claude maakte
Probeer deze week: ...
```

## Regels voor het bijhouden

- De datum is de datum van de les, niet een geschatte datum.
- "Hoe vaak zelf gedaan" telt alleen wat de gebruiker zelf deed, niet wat Claude voordeed.
- Bij Terugkerend werk tel je per taak op. Bij drie stel je een skill voor.
- Vul niets in wat de gebruiker niet gezegd heeft. Leeg laten mag.
